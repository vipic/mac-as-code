# 交互操作树

唯一日常入口：`sh mac.sh`。进入菜单自动清屏，顶部为项目说明，中间为操作区，底部显示可用按键。单选使用 `↑↓` / `j k` 移动、`Enter` 执行；`b` 返回、`q` 退出按下即响应。确认页先展示说明，再在底部固定显示确认问题和 `y` / `Enter` 将执行的操作，长说明可滚动。范围列表直接编辑：空格切换、`Enter` 执行；`a` / `n` 只作用于当前页。

菜单、说明、确认和结果页均支持单键 `q` 退出，主菜单没有 `b`。路径为空时同样支持 `b` / `q`；编辑内容后用 `Esc` 返回、`Ctrl+Q` 退出，字母保持路径含义。长确认内容支持方向键与 PageUp / PageDown 滚动。

## 操作影响

- **根据仓库配置此电脑**：选择范围（配置 / 软件 / Recipe / 全部），只改变电脑，不改仓库清单。所有项目都会列出：已满足项和已安装软件默认勾选，`[需确认]` 项默认不选；已安装软件和 Recipe 右侧显示 `★`。空格切换、`Enter` 执行，`a` / `n` 只作用于当前页。已有软件通常跳过，不删除额外软件；已满足设置会重新写入相同值。系统设置可能重启 Finder / Dock。
- **将该电脑软件同步到仓库**：只追加本机软件到 Brewfile，不安装或卸载软件。某项格式检查失败会撤销该次追加，之前成功追加的内容保留。
- **备份**：新建快照，不删除旧快照；会尝试临时退出 Keyboard Maestro，再恢复其原先运行状态。Ghostty 仅备份 `~/.config/ghostty/`，排除 `*.bak` 与 `.DS_Store`。
- **恢复**：只读快照，改写本机数据。普通文件覆盖前保留 `.before-restore-*`，plist 先导出现有偏好；TextFlash 用 CLI 导入，未先导出其当前数据。恢复前会退出相关应用，结束后不自动重开。
- **返回和退出**：不会执行尚未确认的操作，也不会回滚已经执行的安装、设置或清单追加。执行可能部分成功，「跳过」需看逐项原因，不能把结束汇总理解为全部数据均已迁移。

快照范围、恢复软件映射和校验边界见 [README](../README.md#重置与换机)。缺少依赖或提前失败的步骤可能直接结束当前任务并回主菜单；`Ctrl+C` 可中止当前任务。
