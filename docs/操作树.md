# 交互操作树

入口：`sh init.sh`。所有输入步骤均显示 `b` 返回、`q` 退出程序；`q` 不会执行尚未确认的选择，但不会撤销此前已完成的操作。以下对应不带自动执行参数的交互流程；数字菜单每行一项。

标记：`[查看]` 不应用设置或安装软件；`[选择]` 只改本次临时计划；`[电脑]` 修改本机；`[仓库]` 修改配置清单；`[快照]` 创建备份文件。

```text
sh init.sh
├─ 1 配置这台 Mac
│  ├─ 自动实时检测 [查看]
│  │  └─ 可比较的差异默认选中；已满足项折叠；无法判断/重置类项默认不选
│  ├─ 1 应用已选项
│  │  ├─ 没有选中项 → 提示后返回配置菜单
│  │  └─ 展示将执行的项目 → 确认？
│  │     ├─ n / Enter → 返回配置菜单
│  │     └─ y → 再次实时复核
│  │        ├─ 状态变化 → 更新计划，返回配置菜单重新确认
│  │        ├─ 检测失败 → 停止本次配置，返回主菜单
│  │        └─ 状态未变 → 执行 [电脑]
│  │           ├─ 按需检查安装前置条件
│  │           │  └─ 缺少 CLT → 打开系统安装器，停止；安装后需重新进入
│  │           ├─ 按需等待 App Store 登录
│  │           │  └─ Enter 检测登录；b 返回配置菜单；q 退出程序
│  │           ├─ 应用选中的系统设置；成功应用后重启 Finder
│  │           ├─ 安装选中的软件；需要时安装 Homebrew；可能要求管理员密码
│  │           ├─ 执行选中的 Recipe / GitHub Releases 安装
│  │           ├─ 应用选中的 Dock 设置；成功应用后重启 Dock
│  │           └─ 汇总结果、保存日志和重试计划、更新成功设置的基线 → 主菜单
│  ├─ 2 调整选择 [选择]
│  │  ├─ 1 全部（Enter 默认）
│  │  ├─ 2 软件 / 环境
│  │  ├─ 3 系统设置
│  │  ├─ 4 Dock
│  │  │  └─ 上述四项均进入对应范围的多选列表
│  │  │     ├─ ↑↓ / j k：移动；空格：切换当前项
│  │  │     ├─ a：选中当前范围全部项目（也包含需确认项）
│  │  │     ├─ n：取消当前范围全部选择
│  │  │     ├─ Enter：保存本次调整 → 配置菜单
│  │  │     ├─ b：撤销本次调整 → 配置菜单
│  │  │     └─ q：退出程序
│  │  └─ 0 返回 → 配置菜单
│  ├─ 3 查看详情 [查看]
│  │  └─ 展示差异与需确认项的说明 → 配置菜单
│  ├─ 4 将本机软件加入配置清单
│  │  ├─ 实时审计并更新本机审计缓存 [查看]
│  │  └─ 多选待追加软件（默认全部不选）
│  │     ├─ b / 未选中任何项 → 配置菜单；q → 退出程序
│  │     └─ Enter 且有选中项 → 确认写入清单？
│  │        ├─ n / Enter → 配置菜单
│  │        └─ y → 复核每项并追加 config/Brewfile [仓库]
│  │           └─ 汇总追加结果、更新配置菜单中的计划 → 配置菜单
│  ├─ 5 重试上次失败项 [选择]
│  │  ├─ 无失败记录 → 提示后返回配置菜单
│  │  └─ 实时检测，只选中仍未完成的失败项 → 配置菜单
│  │     └─ 需要再选 1 才开始执行
│  └─ 0 / Enter 返回 → 主菜单
├─ 2 备份这台 Mac
│  └─ 展示目录、备份范围、应用退出提示 → 开始备份？
│     ├─ n / Enter → 主菜单
│     └─ y → 创建带时间和机器名的新快照 [快照]
│        ├─ 临时退出 Keyboard Maestro / Brave [电脑：运行状态]
│        ├─ 复制配置、导出应用数据、生成独立 restore.sh 和校验文件
│        ├─ 正常结束或失败时，尝试恢复上述应用原先的运行状态
│        └─ 展示完成项、未备份项和快照目录 → 主菜单
├─ 3 从备份恢复
│  └─ 列出默认目录中的快照
│     ├─ 0 / Enter → 主菜单
│     └─ 输入快照编号或目录
│        ├─ 目录无效 / 校验文件缺失 / 校验失败 → 停止，返回主菜单
│        └─ 展示来源和内容、校验通过
│           ├─ 1 直接恢复 → 最终恢复确认
│           ├─ 2 先安装快照所需软件，再恢复
│           │  └─ 检测快照对应软件
│           │     ├─ 没有待安装项 → 最终恢复确认
│           │     └─ 展示安装清单 → 确认安装？
│           │        ├─ n / Enter → 主菜单
│           │        └─ y → 立即安装这些软件 [电脑]
│           │           ├─ 安装失败 / 前置条件未满足 → 停止，返回主菜单
│           │           └─ 安装完成 → 最终恢复确认
│           ├─ 0 / Enter → 主菜单
│           └─ 最终恢复确认：恢复上述个人数据？
│              ├─ n / Enter → 主菜单（此前已安装的软件会保留）
│              └─ y → 执行快照内 restore.sh [电脑]
│                 ├─ 新生成的恢复脚本再次校验完整性
│                 ├─ 保留将被覆盖的现有配置为 .before-restore-*
│                 ├─ 退出需要恢复配置的相关应用；不关闭 Ghostty
│                 ├─ 复制文件、导入应用偏好及 TextFlash 数据
│                 └─ 汇总完成 / 未恢复项目 → 主菜单
└─ 0 / Enter 退出
```

## 各类操作的边界

- **应用到电脑**：以仓库清单为目标，只执行已选项。软件通常跳过已安装项，不删除本机额外软件；系统和 Dock 设置会改变选中项对应的偏好。重置 Launchpad、清空并重新固定 Dock、清除密码策略等需确认项目，选中后会执行其明确描述的动作。
- **写入配置清单**：只追加选中的软件到 Brewfile，不反向保存系统偏好，不自动提交 Git，也不安装或卸载软件。
- **备份**：范围为 SSH、Git、Zsh、Ghostty、CleanShot、Keyboard Maestro、Rime、TextFlash 和 Brave 插件本地配置。不会自动保存整个主目录、整个磁盘或所有应用数据。Ghostty 只备份 `~/.config/ghostty/`，排除 `.bak`，不再备份 macOS 专用目录；已有快照的恢复兼容仍保留。
- **恢复**：使用所选快照自身的脚本，因此旧快照遵循生成时的恢复实现。缺少的快照项目会跳过；文件覆盖前留存副本不等于自动回滚整个恢复过程。
- **查看与选择**：不安装软件或应用偏好，但会使用临时计划；软件追加入口的审计还会访问软件数据源并写入本机缓存。

执行可能部分成功。单项安装失败通常记录后继续其他项目；确认取消、流程中断或失败不会自动撤销此前已完成的安装或修改。`Ctrl+C` 会中止当前任务。

`doctor`、`check` 和旧版兼容参数是命令行快捷入口，不是上述数字菜单中的选项，见 README。
